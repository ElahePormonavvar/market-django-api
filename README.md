# web api market

Built with Django REST Framework. Key Features: 

## Features

- User registration and authentication with JWT tokens
- CRUD operations for products via API (Create, Read, Update, Delete)
- Admin panel for managing users and productsmarket

## Installation

- Python 3.x
- Django 3.x or later
- MySQL
